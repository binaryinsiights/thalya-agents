# Modelo-base Thalya

`thalya-base-agent.json` é a cópia operacional do agente de referência Maria,
com a identidade pública renomeada para **Thalya**. O prompt, as regras, as
ferramentas, os limites, os follow-ups e a estrutura da base de conhecimento
foram preservados.

Na implantação de um cliente, este arquivo deve ser importado como modelo e
depois receber os dados reais do cliente: nome da empresa, contatos, horários,
profissionais, valores, convênios, agenda, credenciais e base de conhecimento.

Os dados da Clínica Moreira permanecem no arquivo para manter a referência
funcional completa; eles não devem ser usados sem substituição em outro
cliente.
